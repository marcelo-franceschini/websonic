# Referências e Metadados

Esta pasta armazena apenas metadados do projeto. Nenhum dado com conteúdo da ROM entra aqui.

## Arquivos de referência

- `rom-hashes.txt`: Hashes criptográficos e identificadores da ROM de referência.
- `disasm-commit.txt`: Commit fixado do repositório sonicretro/s1disasm.
- `limite-tamanho.txt`: Limite em bytes para arquivos aceitos no repositório.
- `excecoes-extensoes.txt`: Lista de arquivos permitidos que fogem do padrão de bloqueio.
